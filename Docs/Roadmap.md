# 개발 계획

1~5단계(전투 기본, 무기 슬롯, 1인칭 뷰모델, 경기 흐름, 요원 스킬)는 끝났다. 6단계는 에셋 없이 코드로 할 수 있는 것부터 한다.

## 6단계: 코드로 할 수 있는 것

| 단계 | 내용 | 상태 |
|---|---|---|
| 6-1 칼 공격 | 좌클릭 베기(3연속) / 우클릭 찌르기, 뒤치기 2배, 랙 보상 판정(조준 중심 우선), 스킬 벽 2배, 킬피드 Knife | 완료 |
| 6-2 피격 감속 | 총에 맞으면 잠깐 느려진다(태깅 72.5%, 벽 관통 25%, 산탄 10m 밖 30%). 클라가 받은 이동 시각으로 서버와 같은 계산 → 보정 없음 | 완료 |
| 6-3 점수판·어시스트 | Tab 점수판(요원·궁극기·크레딧·ACS·K/D/A), 어시스트(13.10 규칙 + 섬광·정찰·회복), 전투 점수 | 완료 |
| 6-4 설정 | Esc/F10 설정 창: 감도(발로란트 숫자, 마우스 원시 카운트로 직접 회전)·조준 감도 배율·반전, 조준 토글/누르기, 조준선 모양(미리보기), 내 컴퓨터에 저장(Settings.md) | 완료 |
| 6-5 메뉴·접속 | 데디 서버 기준. 메인 메뉴(이름, 서버 주소로 참가·취소, 개발용 로컬 데디 서버 띄우기), 서버 대기실(최소 인원 → 카운트다운), 게임 중 나가기, 서버 응답이 끊기면 경고 후 20초 뒤 메뉴, 끊기면 메뉴에 이유 표시(Menu.md) | 완료 |
| 6-6 연습용 봇 | 움직이고 쏘는 봇(혼자 연습·테스트용) | 예정 |

## 에셋이 생기면

| 내용 | 필요한 것 |
|---|---|
| 권총(클래식 기본 지급, 권총 상점, 권총 라운드 800 크레딧) | 권총 BP(메시). 코드는 BP가 있으면 자동으로 상점·기본 지급에 올라간다 |
| 1인칭 관전 | 1인칭 팔·무기 애니메이션 |
| 칼·스킬 애니메이션, 이펙트, 소리 | 애니메이션·이펙트·사운드 에셋. 코드는 시각 값만 내놓는다(예: `GetLastMeleeAttackWorldTime`) |
| 미니맵 | 맵 위에서 본 이미지 |
