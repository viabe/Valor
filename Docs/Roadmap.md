# 개발 계획

1~5단계(전투 기본, 무기 슬롯, 1인칭 뷰모델, 경기 흐름, 요원 스킬)는 끝났다. 6단계는 에셋 없이 코드로 할 수 있는 것부터 한다.

## 6단계: 코드로 할 수 있는 것

| 단계 | 내용 | 상태 |
|---|---|---|
| 6-1 칼 공격 | 좌클릭 베기(3연속) / 우클릭 찌르기, 뒤치기 2배, 랙 보상 판정(조준 중심 우선), 스킬 벽 2배, 킬피드 Knife | 완료 |
| 6-2 피격 감속 | 총에 맞으면 잠깐 느려진다(태깅). 이동 예측과 서버 판정이 같게 | 예정 |
| 6-3 점수판·어시스트 | Tab 점수판(처치·사망·어시스트·크레딧·궁극기), 어시스트 판정, 전투 점수 | 예정 |
| 6-4 설정 | 감도, 조준 방식(토글/누르기), 조준선 모양을 저장하고 게임 안에서 바꾸는 창 | 예정 |
| 6-5 메뉴·접속 | 메인 메뉴, 방 만들기(리슨 서버)·IP로 참가 | 예정 |
| 6-6 연습용 봇 | 움직이고 쏘는 봇(혼자 연습·테스트용) | 예정 |

## 에셋이 생기면

| 내용 | 필요한 것 |
|---|---|
| 권총(클래식 기본 지급, 권총 상점, 권총 라운드 800 크레딧) | 권총 BP(메시). 코드는 BP가 있으면 자동으로 상점·기본 지급에 올라간다 |
| 1인칭 관전 | 1인칭 팔·무기 애니메이션 |
| 칼·스킬 애니메이션, 이펙트, 소리 | 애니메이션·이펙트·사운드 에셋. 코드는 시각 값만 내놓는다(예: `GetLastMeleeAttackWorldTime`) |
| 미니맵 | 맵 위에서 본 이미지 |
