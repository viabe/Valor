# 경기 모드(4단계: 매치 흐름)

경쟁전 규칙을 서버 게임 모드 `AValorMatchGameMode`로 구현한다. 데스매치(`AValorGameMode`, `BP_ValorGameMode`)는 그대로 두고, 경기 모드는 그 자식 클래스다.

## 1. 켜는 방법

| 방법 | 설정 |
|---|---|
| PIE | 맵 World Settings → GameMode Override → `ValorMatchGameMode`(C++ 클래스). 캐릭터 BP(`BP_ValorCharacterBase`)는 생성자가 자동으로 고른다 |
| 단독/패키징 실행 | 맵 URL에 `?game=Match`(별칭, `DefaultEngine.ini`). 데스매치는 `?game=DM` |
| 빠른 확인 | URL 옵션으로 단계 시간 변경: `?PreMatchTime=3?BuyTime=6?RoundTime=20?RoundEndTime=3?MatchEndTime=5` |

지금 테스트 맵(`ThridPersonExampleMap`)은 World Settings가 `BP_ValorGameMode`(데스매치)라 PIE 기본은 데스매치다.

### PIE 테스트 방법

1. 맵 World Settings → GameMode Override를 `ValorMatchGameMode`로 바꾼다(저장하지 않으면 맵은 그대로).
2. Play 옆 ⋮ → Number of Players를 2(서로 다른 팀) 또는 3(TeamA 2명: 아군 사격 확인), Net Mode를 Play As Listen Server로 둔다.
3. 개발용 콘솔 명령(` 키):

| 명령 | 효과 |
|---|---|
| `ValorCredits 9000` | 내 크레딧을 정한다(1라운드 800으로는 경량 실드만 살 수 있다) |
| `ValorSkipPhase` | 지금 단계를 바로 끝낸다. 교전을 건너뛰면 시간 종료(수비 승) |
| `Valor.HUD.TextScale 1.6` | HUD 글자·패널 배율(0이면 기본 1.4) |

| 확인할 것 | 방법 |
|---|---|
| 구매 단계 | 라운드 시작 뒤 30초 동안 B로 상점을 연다. 이동·사격은 된다(발로란트). 메뉴가 열려 있으면 클릭은 총을 쏘지 않는다 |
| 구매·되팔기 | B → 칸 클릭. 산 칸은 SELL로 바뀌고 다시 누르면 환불. 다른 총을 사면 앞의 것은 자동 환불 |
| 처치·전멸 | 교전에서 상대를 죽이면 +200, 전멸시키면 라운드 승리(+3000), 진 쪽 +1900 |
| 아군 사격 | 3명일 때 같은 팀(TeamA 둘)끼리 쏘면 피해가 없고 탄이 지나간다 |
| 장비 가져가기 | 살아남으면 다음 라운드에 총·남은 실드를 그대로 들고 시작 |
| 공수 교대·경제 초기화 | `ValorSkipPhase`를 반복해 12라운드를 넘기면 공수가 바뀌고 크레딧이 800이 된다 |
| 시간 종료 | 아무도 죽지 않으면 100초 뒤 수비 승 |

## 2. 라운드 흐름

접속 대기(첫 접속 뒤 3초) → [구매 30초 → 교전 100초 → 라운드 종료 7초] 반복 → 경기 종료 15초 → 새 경기.

| 단계 | 이동 | 사격 | 상점 |
|---|---|---|---|
| 접속 대기 | 됨 | 됨 | 닫힘 |
| 구매 | 됨 | 됨(메뉴가 열려 있으면 클릭은 메뉴 선택) | B로 열기 |
| 교전 | 됨 | 됨 | 닫힘 |
| 라운드 종료 | 됨 | 됨(결과는 안 바뀜) | 닫힘 |
| 경기 종료 | 됨 | 안 됨 | 닫힘 |

- 라운드 시작: 모든 플레이어를 팀 스폰에 새로 스폰한다. 살아남은 사람은 주무기·보조무기·남은 실드를 가져간다. 죽은 사람은 칼만 든다(권총 BP가 생기면 클래식). 바닥의 총은 모두 지운다(맵에 놓인 총 포함).
- 승리: 상대 팀 전멸, 또는 시간 종료(수비 승). 스파이크(설치·해체·폭발)는 다음 작업이다.
- 13선승. 12라운드 뒤 공수 교대와 경제 초기화. 12:12면 연장전(2점 차, 매 라운드 공수 교대, 매 라운드 크레딧 5000).
- 혼자 연습: 라운드 시작 때 사람이 없던 팀은 전멸로 치지 않는다. 혼자면 시간 종료로만 끝난다.
- 죽으면 다음 라운드까지 시체 시점에 머문다. 아군 관전은 아직 없다.
- 아군 사격 없음. 탄은 아군을 그대로 지나간다(판정 단계에서 아군 제외, 피해 적용 단계에서도 한 번 더 막음).

## 3. 경제와 상점

| 항목 | 값 |
|---|---|
| 시작(1라운드, 후반 첫 라운드) | 800. 상점에 권총이 없는 동안은 가장 싼 총 값(지금 버키 850)으로 올려 총을 하나는 살 수 있게 한다. 권총 BP가 들어오면 저절로 800 |
| 승리 | 3000 |
| 패배 | 1900 / 2400 / 2900(연패 1·2·3+) |
| 적 처치 | 200 |
| 연장전 | 매 라운드 5000 |
| 상한 | 9000 |

- 상점 목록: `AValorGameState` 생성자의 총 BP 경로(에셋이 있는 것만), 가격·분류는 각 총 데이터 에셋의 `Cost`·`Category`. 실드는 경량 400 = 25, 중형 1000 = 50.
- 권총(Sidearm 분류)은 `bAllowSidearmPurchases = false`라 상점에서 뺀다. 권총 BP(BP_Classic 등)가 들어오면 켠다.
- 구매 단계에만 산다. 이번 라운드에 산 것은 다시 눌러 되판다(전액 환불). 같은 슬롯 총을 다시 사면 이번 라운드에 산 앞의 총은 자동 환불된다. 가져온·주운 총은 바닥에 떨어진다.
- 구매 메뉴: 캔버스 HUD 클릭 영역. B로 열면 커서가 보이고 시점 회전이 멈춘다. 구매 단계가 끝나거나 죽으면 닫힌다.

## 4. 팀과 스폰

- 팀 배정: 인원이 적은 팀, 같으면 TeamA. 1~12라운드는 TeamA 공격.
- 팀 스폰: PlayerStart의 Player Start Tag를 `Attack` / `Defense`로 달면 그쪽 스폰이다.
- 태그가 없는 맵의 대체 규칙: 시작점이 둘 이상이면 서로 가장 먼 두 점 기준으로 두 무리로 나누고 상대 무리를 바라보게 세운다. 하나뿐이면 공격은 그 자리, 수비는 그 앞쪽 바닥(최대 20m, 벽에 막히면 줄임)에 마주 보게 세운다. 지금 테스트 맵은 시작점이 하나라 두 팀이 약 8.8m 떨어져 선다.
- 같은 스폰의 팀원은 옆으로 1.2m씩 비켜 선다(겹치면 다음 칸).

## 5. 네트워크

| 상태 | 위치 | 복제 |
|---|---|---|
| 단계, 단계 끝 시각, 라운드 번호, 공격 팀, 점수, 라운드 결과, 경기 승자 | `AValorGameState` | 모두에게. 남은 시간은 클라가 서버 시간 추정치로 센다 |
| 팀, 크레딧 | `AValorPlayerState` | 모두에게(트레이드오프: 적 크레딧도 보인다) |
| 이번 라운드 구매 목록 | `AValorPlayerState` | 본인에게만(상점 "SELL" 표시) |
| 가져갈 장비 | `AValorPlayerState::CarriedLoadout` | 서버 전용 |
| 구매·되팔기 | `AValorPlayerController::ServerBuy*/ServerSell*` | 서버 RPC(Reliable). 규칙 검사는 게임 모드 |

- 구매 단계 이동·사격 잠금은 기본으로 끈다(`bFreezePlayersDuringBuyPhase`, `bBlockFireDuringBuyPhase`, 발로란트처럼 움직이고 쏠 수 있음). 켜면 이동은 `UValorCharacterMovementComponent::GetMaxSpeed`가 복제된 단계를 보고 0을 돌려주고(예측과 맞음), 사격은 클라 발사(`TryFireLocalShot`)와 서버 검증(`ValidateShotRequest`)이 같은 `IsWeaponFireAllowed`를 본다.
- 스폰 장벽이 아직 없어서 구매 단계에 상대 스폰까지 갈 수 있다(장벽은 다음 작업).

## 6. 확인 도구

| 도구 | 내용 |
|---|---|
| `Valor.Match.Rules.*` | 보상, 승리 조건(연장 2점 차), 공수, 경제 초기화 라운드, 팀 배정, 스폰 나누기 |
| `Valor.Tools.MatchFlow` | 혼자 짧은 경기: 실제 B 키로 메뉴 열기·닫기, 실제 마우스 클릭으로 실드 구매(총은 안 쏨), 구매 단계 이동·사격 가능, 실드·총 구매·되팔기·바꿔 사기, 시간 종료 수비 승, 패배 보상, 장비 가져가기, 화면 캡처(`Saved/MatchFlow`) |
| `Valor.Tools.MatchNet.Host/Client` | 리슨 서버 + 클라: 서로 다른 팀·스폰, 전멸 승, 처치·승패 보상 |

## 7. 알려진 문제와 다음 작업

- 캐릭터 BP 이동 컴포넌트: `BP_ValorCharacterBase`가 Valor 이동 컴포넌트 도입(2026-11-09) 전에 저장돼 있어서, `-game`·패키징에서는 엔진 기본 이동 컴포넌트가 쓰였다(걷기, 무기별 이동 속도가 빠져 있었음). 에디터는 BP를 열 때 다시 컴파일해 가려졌다. `-run=ValorRepairCharacterBlueprint` 커맨드렛으로 다시 컴파일해 저장했다(엔진 ResavePackages는 컴파일하지 않아 고쳐지지 않는다).
- 입력 컨텍스트: 무기 슬롯 키(1/2/3/G/휠)와 B를 담는 런타임 입력 컨텍스트를 캐릭터마다 새로 만들어서, 지워진 캐릭터의 컨텍스트가 입력 서브시스템에 남아 같은 키를 먼저 가져갔다. 경기 모드는 라운드마다 캐릭터를 새로 스폰하므로 B가 열리지 않았다(데스매치 부활 뒤 1/2/3/G도 같은 문제). 컨텍스트와 액션을 컨트롤러 밑에 한 벌만 두도록 고쳤다(`UValorInputRouterComponent::SetupWeaponSlotInput`).
- 다음: 스파이크(소지·설치 4초·해체 7초·폭발 45초, 설치 보너스 300), 스파이크 지점(A·B) 볼륨과 테스트 맵 배치, 관전, 스폰 장벽, 권총 구매.
