# 설정(6-4)

감도, 조준 방식, 조준선 모양을 게임 안 설정 창에서 바꾸고 내 컴퓨터에 저장한다. 바꾸면 바로 적용되고 바로 저장된다.

## 1. 여는 방법

| 어디서 | 키 |
|---|---|
| 패키지 / `-game` 실행 | `Esc` 또는 `F10` |
| 에디터 PIE | `F10`(PIE에서 `Esc`는 플레이를 끝낸다) |
| 콘솔 | `ValorSettings` |

- 구매 메뉴가 열려 있으면 `Esc`는 상점부터 닫는다. 설정 창 위에서는 상점(`B`)이 열리지 않는다.
- 창이 열려 있는 동안은 커서가 보이고, 시점·사격·조준·스킬·관전 클릭이 멈춘다. 이동은 된다.
- 요원 선택·관전 중에도 열 수 있다. 그동안 아래 창(상점·요원 선택)은 그리지 않는다.

## 2. 항목

### 조작 탭

| 항목 | 값 | 기본 |
|---|---|---|
| SENSITIVITY | 발로란트와 같은 숫자. 1이면 마우스 1카운트에 0.07도. 막대는 0.05~5, `+/-`와 콘솔은 0.001~10 | 2.5(아래 4절) |
| SCOPED MULTIPLIER | 조준(ADS·저격 줌) 중 감도 배율. 1이면 줌 배율만큼 느려진다(밴달 0.8배, 오퍼레이터 1단 0.4배·2단 0.2배) | 1 |
| INVERT MOUSE | 위아래 반전 | 끔 |
| AIM DOWN SIGHTS | TOGGLE(누를 때마다 조준 ↔ 해제) / HOLD(누르는 동안만) | TOGGLE |
| SNIPER SCOPE | 저격총 줌. TOGGLE은 1단 → 2단(오퍼레이터) → 해제, HOLD는 누르는 동안 1단 | TOGGLE |
| AUTO RE-SCOPE | 쏘면 풀리는 저격총(오퍼레이터·마샬)을 다음 발 준비가 끝나면 다시 조준 | 끔 |

창 아래에 지금 감도로 360도 도는 마우스 거리(400/800/1600 DPI)를 보여 준다. 다른 게임 감도와 맞출 때 쓴다.

### 조준선 탭

위에 미리보기(어두운 배경 / 밝은 배경, 게임과 같은 크기)가 있다.

| 묶음 | 항목 |
|---|---|
| GENERAL | 색(견본 8개: 흰색·초록·연두·노란 연두·노랑·하늘·분홍·빨강, 다른 색은 `ValorCrosshairColor`), 외곽선 켬/끔·투명도·두께, 가운데 점 켬/끔·투명도·두께 |
| INNER LINES / OUTER LINES | 보이기, 투명도, 길이, 두께, 간격, 움직이면 벌어짐(MOVEMENT ERROR), 쏘면 벌어짐(FIRING ERROR) |

- 길이·두께·간격은 1080p 기준 픽셀이고 해상도에 비례한다.
- 기본값은 설정이 생기기 전 HUD에 박혀 있던 값과 같다(처음 열어도 화면이 바뀌지 않는다).
- 조준(ADS) 중 점과 저격 조준경 가운데 점도 같은 색을 쓴다.

`RESET TAB`은 보고 있는 탭만 기본값으로 되돌린다.

## 3. 콘솔 명령(정확한 숫자)

| 명령 | 효과 |
|---|---|
| `ValorSens 0.4` | 감도 |
| `ValorScopedSens 1` | 조준 감도 배율 |
| `ValorCrosshairColor 00FF00` | 조준선 색(6자리 16진수, `#` 있어도 됨) |
| `ValorSettings` | 설정 창 열기·닫기 |
| `Valor.Input.RawMouseLook 0` | 예전 시점 경로로 되돌린다(비교용, 아래 4절). 기본 1 |

## 4. 마우스 시점이 바뀐 점

- 예전: 입력 매핑(IMC_Player)의 `IA_Look` 값으로 돌렸다. 에셋에 든 배율(0.07)과 엔진 배율(2.5)이 곱해져 1카운트에 0.175도였다. 이것은 발로란트 감도 2.5와 같다(도구로 잰 값).
- 지금: 컨트롤러가 이번 프레임 마우스 원시 이동량(카운트)을 읽어 `0.07도 × 감도`로 직접 돌린다(`AValorPlayerController::UpdateRotation`). 입력 매핑 값은 시점에 쓰지 않는다.
- 왜: 입력 매핑 값에는 에셋 배율과 엔진 배율이 섞여 "감도 1 = 몇 도"를 코드에서 알 수 없다. 원시 카운트를 쓰면 발로란트 감도를 그대로 옮겨 올 수 있고 프레임과도 무관하다.
- 기본 감도는 2.5로 두었다(예전과 같은 속도). 발로란트에서 쓰던 감도가 있으면 그 숫자를 넣으면 같은 거리로 돈다.
- 게임패드 오른쪽 스틱은 예전 경로 그대로다(같은 `IA_Look`에 묶여 있어서, 마우스가 움직이지 않은 프레임에만 그 값으로 돌린다). 감도 설정은 마우스에만 적용된다.
- 네트워크는 바뀌지 않았다. 회전 결과는 전과 같이 이동 요청으로 서버에 간다.

### 조준 감도

- 계산: `조준 중 감도 = 감도 × 조준 감도 배율 × 줌 비율`.
- 줌 비율은 `tan(줌 FOV/2) / tan(힙 FOV/2)`이다. 화면 중앙 근처에서 같은 마우스 거리가 같은 화면 거리를 움직이게 한다.
- 발로란트가 배율 1에서 이렇게 하는지는 공개 자료가 없어 추정이다. 조준이 너무 느리거나 빠르면 배율로 맞춘다.

## 5. 저장 위치

- 파일: `Saved/Config/WindowsEditor/GameUserSettings.ini`(에디터·`-game`). 패키지 빌드는 `Saved/Config/Windows/GameUserSettings.ini`.
- 구역: `[/Script/Valor.ValorUserSettings]`, 키는 `Controls=(...)`, `Crosshair=(...)`.
- 해상도 등 엔진 설정 구역은 건드리지 않는다.
- 손으로 고친 값이 범위를 벗어나거나 깨져 있으면, 읽을 때 쓸 수 있는 값으로 돌린다.
- 에디터 PIE 창 여러 개는 같은 설정을 쓴다(한 컴퓨터의 한 파일).
- 복제하지 않는다. 내 컴퓨터에서만 쓰는 값이다.

## 6. 확인 도구

| 도구 | 내용 |
|---|---|
| `Valor.Settings.Rules` | 감도 → 도, 반전, 줌 비율(밴달 0.8·오퍼레이터 0.4), 막대 값 맞추기, 저장값 검사(NaN·범위), 기본 조준선 = 예전 HUD 값, 색 입력 |
| `Valor.Tools.SettingsFlow` | 데스매치 혼자. 예전 경로 속도 측정, 실제 마우스 입력 100카운트로 감도 0.5 = 3.5도(좌우·위·반전), 실제 우클릭으로 HOLD/TOGGLE, 조준 중 2.8도, 실제 F10으로 창 열기(커서·시점 멈춤·사격 막힘), 클릭 영역으로 값 바꾸기, 두 탭과 게임 조준선 캡처(`Saved/SettingsFlow`), 저장 파일 확인, 실제 Esc로 닫기. 끝나면 사용자 설정을 처음대로 되돌린다 |

실행:

```
UnrealEditor.exe Valor.uproject "/Game/Maps/ThridPersonExampleMap?game=DM" -game -windowed -ResX=1280 -ResY=720 -ExecCmds="Automation RunTests Valor.Tools.SettingsFlow; Quit"
```

## 7. 나중에

- 설정 창과 미리보기는 캔버스로 그렸다(글자는 기본 폰트라 영어). 디자인 단계에서 UMG로 옮긴다. 설정 값 구조(`UValorUserSettings`)는 그대로 쓴다.
- 키 바꾸기, 그래픽·소리 설정, 조준선 코드 가져오기는 아직 없다.
